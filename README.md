# Artisanal Programming 🎨

这是一个用于存放手写代码和各种实验项目的个人仓库。


## 🛠 开发环境
该项目建议使用 Python 3.11 环境。

### 环境配置
1. **创建 Conda 环境**:
   ```bash
   conda create -n artisanal python=3.11 -y
   ```

2. **激活环境**:
   ```bash
   conda activate artisanal
   ```

3. **安装依赖**:
   ```bash
   pip install -r requirements.txt
   ```
